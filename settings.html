Display

Which look each page starts with: icon mode shows each ingredient's picture, word mode shows its name. It applies everywhere at once - the ingredients list, the cauldron, and the graphs. You can still flip a single page on the spot with its own button; this is just what you get when a page opens. Saved to your repo, so it follows you to your other devices.

Your data

Move your data between devices, or keep a backup. Export downloads everything below as one file; Import replaces everything with whatever file you pick, so back up with Export first if you're not sure.

Included: ingredients, brew log, potential pairings, colors, all the reference lists, any tabs you've added, and these settings.
Not included: uploaded pictures (ingredient icons/drink photos) - those live in the repo's Images folder.

GitHub connection

This device is connected to a GitHub repo for syncing (see github-storage.js). Only needed if you're switching to a different repo or token.
